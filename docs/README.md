# 使用文档

用主题建站、写内容、改设置、部署站点与更新主题的说明。

## 范围

本篇覆盖：使用文档的篇目、阅读顺序与常见入口。前置：一个可以运行的仓库，见[安装与运行](install.md)。

## 阅读顺序

按顺序读，需要时再跳到对应篇。

| # | 篇目 | 内容 |
|---|---|---|
| 1 | [安装与运行](install.md) | 获取主题、安装依赖、首次运行、目录结构、常用命令 |
| 2 | [内容与写作](content.md) | 五个内容区、文件开头的设置、系列与版本、正文写法、图片与附件 |
| 3 | [主题设置](settings.md) | 七组设置、站点图标、浏览数据 |
| 4 | [后台使用](admin.md) | 概览、主题、写作、资源、快照五个页面 |
| 5 | [部署上线](deploy.md) | 构建、GitHub Pages、其他托管、站点地址与子目录 |
| 6 | [主题更新](update.md) | 同步主题新版本、站点自有文件、冲突处理 |
| 7 | [常见问题](faq.md) | 端口、缓存、图标、反向代理、构建失败 |

## 常见入口

- 建站：从[安装与运行](install.md)开始，再按顺序读到部署。
- 写内容：看[内容与写作](content.md)，也可以在本地后台的写作页新建条目。
- 改设置：看[主题设置](settings.md)，或打开本地后台的主题页。
- 部署：看[部署上线](deploy.md)。
- 更新主题：看[主题更新](update.md)。

## 其他文档

- [开发文档](developers/)：改主题代码、维护仓库、发布版本。
- [Agent 文档](agents/)：本地 LLM 与 Agent 的仓库地图、事实台账与改动入口。
