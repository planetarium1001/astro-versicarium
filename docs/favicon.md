# 站点图标

> 本文档为使用文档，不涉及代码、开发等内容。代码分层、命令参数与实现细节见[开发文档：站点图标](developers/favicon.md)。

站点自带一套默认图标，由 `DeepSeek V4.1 Flash 1017`  制作。图标出现在浏览器标签页和手机主屏上；换好之后本地刷新就能看到效果。

没改过设置时，站点一直使用仓库里自带的图标。想换回来，把设置项清空即可。

上传的图标与设置都属于站点自己的文件，主题更新不会覆盖。

## 在后台更换

1. 本地运行 `npm run dev`，打开后台的「主题 → 站点设置」。后台只在本地开发环境可写，线上是只读页面。
2. 在「站点图标」里上传 PNG：建议用正方形，边长 16–512 像素，不超过 256KB。
3. 只传标签页图标就够了；触摸图标留空时会复用它。需要单独的主屏图标，再传第二张。
4. 保存设置，重新打开页面确认。

上传后会按源图生成几种尺寸，换图后这些会一起更新：

| 尺寸 | 用途 |
| --- | --- |
| 16 与 32 像素 | 浏览器标签页 |
| 180 像素 | 手机主屏 |
| 192 与 512 像素 | 安装到桌面后的图标 |
| 旧格式图标 | 老浏览器与直接访问 `/favicon.ico` |

## 用 SVG

SVG 不能在后台上传。把它放到 `public/`，然后在站点设置里填路径。

- 可以写 `/favicon.svg`，也可以写 `public/favicon.svg`，两种写法指向同一个文件。
- 只支持站点自己的文件，不能填外部网址。
- 文件名可以自己取，扩展名必须是 `.svg`。
- SVG 只用于浏览器标签页；手机主屏图标仍然要用 PNG。

## 图标缺失时的回退

浏览器按顺序找图标，找到能用的就停：

1. 设置里填的标签页图标，文件存在时直接使用；
2. 否则用生成好的小尺寸图标；
3. 生成结果也没有时，用站点自带的默认图标。

主屏图标单独一套顺序：设置里填了就用它；没填就沿用标签页图标；再没有就用生成的 180 像素图标；都没有时用自带的主屏图标。

路径写错或文件放错位置时，页面不会出现裂图，会继续往下找一个能用的图标。

## 本地验证

换了图标路径后刷新页面即可；换了源图、想让生成的尺寸一起更新时，重启本地开发服务器。确认标签页图标与手机主屏图标都换了。

## 换完没生效的检查

1. 浏览器缓存可能还留着旧图标，用强制刷新或换无痕窗口再看。
2. 确认文件放进了 `public/`，设置里的路径与文件名完全一致。
3. 线上站点还要检查反向代理，见下一节。

## 反向代理

站点前面有反向代理、访问控制或人机验证时，图标请求可能被拦成网页。表现是标签页空白，直接用地址打开却能显示图片。

处理办法：

- 让代理放行图标的实际路径，常见的是 `/favicon.ico` 与 `/images/site/` 开头的文件；
- 放行后确认返回的是图片类型，不是网页；
- 缓存会让修复后的图标不更新，换无痕窗口再试。
