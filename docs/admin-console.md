# 后台控制台

入口为 `/admin/`，只在 `npm run dev` 下具备读写能力。生产产物中的后台是只读静态壳，`/api/admin/*` 一律返回 404。导航包含概览、主题、写作、资源、快照，路由定义在 `src/lib/admin-console/routes.ts`。

## 概览

汇总内容规模、标签分布、字数与最近条目，读取各集合的已发布条目与草稿数量。开发环境下显示维护者视图（含草稿）；生产环境按 `site.json` 的 `adminOverview.publicVisible` 决定是否输出公开版本，关闭时显示 `adminOverview.hiddenMessage` 的文案。

## 写作

内容管理控制台，覆盖 `blog`、`projects`、`bits`、`devlog`、`about` 五个集合。各集合的能力矩阵定义在 `src/lib/admin-console/content-collections.ts`。

| 集合 | 新建 | 删除 | 草稿 | 正文图片上传 | 图片选择器 |
| --- | --- | --- | --- | --- | --- |
| `blog` | 是 | 是 | 是 | 是 | 否 |
| `projects` | 是 | 是 | 是 | 是 | 是 |
| `bits` | 是 | 是 | 是 | 否 | 是 |
| `devlog` | 是 | 是 | 是 | 是 | 是 |
| `about` | 否 | 否 | 否 | 否 | 否 |

主要能力：

| 能力 | 说明 |
| --- | --- |
| 新建与编辑 | 按标题生成 `YYYY-MM-DD-title` 形式的条目 ID，写入对应集合目录 |
| 草稿状态 | 切换 `draft`，列表可据此筛选 |
| 正文编辑 | 开发环境挂载 Markdown 编辑器，支持插入图片、图库与公式 |
| 列表操作 | 按集合与草稿状态过滤、排序、正文搜索、分页、批量改状态与批量导出 |
| 删除 | 按集合能力开放；`about` 是固定单页，不支持删除 |

编辑页按 `[collection]/[edit]/[...entryId]` 组织，`/admin/content/` 为列表与批量操作入口，对应 API 在 `src/pages/api/admin/content/`。`about` 的正文只有一份，标题与副标题的覆盖值来自 `page.json`。

## 资源

`/admin/resources/` 把图片与附件放在同一个工作区；旧地址 `/admin/images/` 由 `astro.config.mjs` 301 到新地址。左侧内容库按集合 → 系列 → 版本/条目 → 目录展开，默认只展开到集合一级；目录面板可整体收起，宽度可拖拽（分割条，键盘左右键微调，双击复位）。树与预览之间可以横向滚动查看长条目名。

| 操作 | 说明 |
| --- | --- |
| 浏览与筛选 | 按集合、系列、版本/条目、目录、引用状态、类型、日期与关键词筛选，状态写入 URL |
| 上传 | 图片落到当前条目 `images/`，附件落到 `files/` |
| 批量操作 | 重命名、移动、删除前确认；选择状态跟随当前筛选 |
| 详情抽屉 | 复制路径 / Markdown 引用、重命名、移动、删除、导出条目 ZIP；文本附件（`txt` / `md` / `json` 等）显示文本预览 |
| 导入导出 | 资源页支持导入整条目 ZIP；导出走内容接口 |
| 引用状态 | 统计正文与 frontmatter 的引用次数，区分已引用、未引用与孤儿 |

预览区自身滚动，文件统计与分页固定在工作区底部。列表状态体现在 URL 查询参数（`collection`、`series`、`entry`、`dir`、`ref`、`type`、`q`、`page`）。云端来源需要配置对象存储凭据，逻辑在 `src/lib/admin-console/image-cloud-storage.ts`。

## 主题

编辑全部主题设置。服务端按 `src/data/settings/` 的五个文件存储，后台界面拆成六个分组。

| 分组 | 对应设置 | 内容 |
| --- | --- | --- |
| 站点设置 | `site.json` | 站点标题、默认 SEO 描述、站点语言、页脚年份与版权、窄屏站点标题宽度、页面外缘间隙、后台概览文案、站点图标、备案信息（含显示范围）、社交链接 |
| 侧栏设置 | `shell.json`，以及 `ui.json` 的 `layout.sidebarDivider`、`sidebarActions` | 侧栏站点名、窄屏标题、引用文案、导航项的标签 / 装饰符 / 顺序 / 可见性、侧栏分隔线、侧栏图标显隐 |
| 首页设置 | `home.json` | Hero 图与替代文本、导语主文案与补充文案、更多入口 |
| 内页设置 | `page.json`，以及 `ui.json` 的 `articleMeta`、`viewStats`、`floatStack`、`readingMode` | 各列表页标题与副标题、列表页 RSS 开关、`/bits/` 默认作者、文章元信息、浏览数据、浮动操作列 |
| 代码显示 | `ui.json` 的 `codeBlock` | 代码块行号 |
| 排版字体 | `ui.json` 的 `typography` | 正文字体、正文副本、等宽、品牌四个角色 |

窄屏标题（`shell.titleNarrow`）与侧栏站点名同组：留空时在渲染层回落到站点名，长度上限 60；`site.titleMaxPercent` 限制窄屏下标题的可渲染宽度，范围 10–100。

站点图标只传一张标签页 PNG 即可：触摸图标留空时渲染层会复用它，后台预览显示为“复用标签页图标”的虚线状态；需要单独的主屏图标再传第二张。SVG 不提供上传，需手动放到 `public/` 并写进 `site.json`。完整规则见 [favicon.md](favicon.md)。

备案信息显示范围由 `site.filings.scope` 控制：默认 `all` 在全部公开页面渲染，`root` 只在站点根目录渲染；子路径部署时 base 同样算根目录。

### 校验

表单内联预览随输入实时更新，覆盖页脚、备案、文章元信息、浏览数据、首页文案，以及 Hero 图、favicon、`/bits/` 默认头像。检查配置先执行客户端校验，再带 `dryRun=1` 请求 `/api/admin/settings` 预检；两步通过后提示检查通过，否则列出问题并聚焦对应字段。

设置文件的任何读取诊断都会让控制台进入只读状态并列出需要修复的文件与字段，不再接受保存：JSON 非法、根节点不是对象、读取失败，或存在会被静默修补的字段值。渲染与构建不受影响，非法或缺省的字段按内置默认值兜底。

### 拖拽排序与序号

侧栏导航行与社交链接行支持重排：

- 抓住该行最右侧的拖动锚点上下拖动；也可聚焦锚点后用 `↑` / `↓` 移动，移动后焦点保留在原锚点上，便于连续操作；
- 放下后按 DOM 顺序把序号输入框重写为 `1..N`，数字即输入框的值；
- 控制台处于只读状态、正在校验或正在保存时，表单控件被禁用，此时不响应拖拽。

侧栏导航的序号范围是 1–999。社交链接另有可见性规则：可见行按序号排在前，未填写的不可见行随后，结构隐藏行垫底，同号保持原有先后；隐藏行仍参与编号，所以可见行的序号始终连续。社交链接最多 3 个预置项加 8 条自定义项。

### 保存

保存把当前草稿连同 `revision` 提交到 `/api/admin/settings`。服务端在写锁内校验版本与字段，通过后以文件事务写入 `src/data/settings/*.json` 并清理缓存。检测到外部更新时返回 409，控制台暂停保存并保留草稿，提示重新同步配置。

「重置更改」丢弃草稿回到最近一次读取到的配置。「重新检测」重新拉取配置并刷新 `revision`。

## 快照

导出与导入设置快照，用于迁移或备份。导出内容为 `settings` 作用域，不包含内容、图片与凭据，包结构含 `schemaVersion`、生成时间与排除项清单，接口为 `src/pages/api/admin/data/settings.ts`。

## 常见操作路径

| 目标 | 路径 |
| --- | --- |
| 新建一篇博客 | `/admin/content/` → 选博客 → 新建 |
| 改站点标题或备案号 | `/admin/theme/` → 站点设置 |
| 改窄屏标题或侧栏导航 | `/admin/theme/` → 侧栏设置 |
| 开关浏览数据或浮动按钮 | `/admin/theme/` → 内页设置 |
| 替换首页 Hero 图 | `/admin/theme/` → 首页设置，或在 `/admin/images/` 上传后选择 |
| 批量删除草稿 | `/admin/content/` → 按草稿筛选 → 选中条目 → 批量操作 |
| 迁移到另一台机器 | `/admin/data/` → 导出快照，在新环境导入 |
| 管理图片或附件 | `/admin/resources/` → 选条目 → 上传或批量操作 |

## 写入流程

写入分为三类：主题设置写入 `src/data/settings/*.json`，内容写入 `src/content/**`，图片写入 `public/**` 或云端存储。三类请求都带版本标识，服务端在写锁内校验版本与字段，通过后以文件事务方式落盘并清理相关缓存，避免并发保存互相覆盖。

## 开发环境边界

可写能力由构建输出模式区分：开发环境为 `server`，写入接口可用；生产构建为 `static`，后台页面输出静态只读壳。`npm run check:prod-artifacts` 在产物上断言后台各页面不含写入相关的界面标记，且不输出导航入口。

开发环境使用的界面偏好（顶部导航可见性、侧栏导航模式、编辑器默认布局）保存在浏览器 localStorage，不写入仓库文件。
