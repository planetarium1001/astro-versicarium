# 后台使用

> 本文档为使用文档，不涉及代码、开发等内容。代码分层、命令参数与实现细节见[开发者文档：后台控制台](developers/admin-console.md)。

后台是主题自带的内容管理界面，用来写内容、管理图片和修改站点设置。它默认直接读写仓库里的文件，不需要数据库。

后台只在本地开发时能保存。用 `npm run dev` 启动后，打开 `http://localhost:4321/admin/` 进入；构建出来的线上站点只有只读页面。

## 什么时候能用

- 在本地用 `npm run dev` 启动站点，在地址后面加 `/admin/` 进入后台。
- 新建内容、修改设置会落到仓库文件；图片默认也写进仓库，配置对象存储后进入云端。刷新页面就能看到效果。
- 线上站点是构建好的静态页面，后台不能写入，也不显示编辑控件。
- 后台不会自动提交改动，写完照常检查并提交仓库。

## 概览页

概览显示内容数量、热门标签、总字数、最近条目和写作活动。本地开发时草稿也会列出来并标注；线上是否显示公开概览由站点设置决定，关闭时显示一段隐藏提示。

## 主题设置

主题页把设置分成七组，保存后写入 `src/` 下的五个设置文件。也可以手动改这些文件，刷新页面后生效。

| 分组 | 管什么 |
| --- | --- |
| 站点设置 | 站点名称、描述、语言、时区、页脚、备案号、社交链接、站点图标，以及窄屏标题宽度、页面外缘间隙、浮动按钮位置这类布局尺寸 |
| 侧栏设置 | 侧栏的站点名、窄屏标题、引语、导航项与顺序、分隔线、订阅按钮、主题按钮和后台入口 |
| 首页设置 | 首页头图、导语、补充文案，以及「更多」入口的文字与链接 |
| 内页设置 | 各列表页的标题与副标题、归档显示全部还是最新版、动态默认作者、文章信息、日期显示、浏览数据、浮动按钮与分页 |
| 条目版本 | 版本名称显示在哪里：隐藏、放在版本号前或版本号后 |
| 代码显示 | 代码块是否显示行号 |
| 排版字体 | 正文、引用、等宽与品牌四个字体用途，以及字库覆盖范围（全部字符或只覆盖常用字） |

改完点「检查配置」，后台只校验并列出会变化的项，不写文件；确认后点「保存」，只写入有变化的分组。想放弃本轮修改，点「重置更改」。

如果设置文件在别处被改过，或另一个窗口先保存了，页面会提示文件已在外部更新，并保留你当前填的内容。点「重置更改」回到最新内容再改，点「重新检测」重新读取文件和状态。

设置文件出现格式错误时，后台进入只读状态，列出出问题的文件、位置和原始错误。先修好文件，再点「重新检测」。

站点图标可以在站点设置里上传 PNG：不超过 256KB，边长 16–512 像素，接近正方形。想用 SVG，把文件放进 `public/`，再在站点设置里填写路径。

## 写作

写作页按五个区列出内容：文章、项目、动态、开发日志和关于页。列表可按区、草稿状态、年份、标签、排序与关键词筛选。

- 新建条目默认是草稿，列表里会标出；编辑完保存，取消草稿即为发布。
- 编辑器提供 Markdown、预览、大纲，以及图片、画廊、公式、折叠内容和摘要分隔的插入。
- 博客条目可以「新建版本」：以系列最新版为模板生成一份新草稿，其余区没有这个动作。
- 删除的条目会移到回收站目录，不会马上从磁盘消失，需要时可以手动移回。
- 支持批量改发布状态、删除与导出源文件，一次最多 200 条。
- 关于页是固定单页，只能编辑正文。
- 保存博客正文时，如果正文引用的本地图片不存在，会拒绝保存。

图片与附件的写法见[内容与写作](writing.md)。

## 资源

资源页把图片和附件放在同一个工作区。左侧目录按内容区、系列、版本或条目展开，共享资源是每个内容区共用的一份。

- 上传的图片和附件放到当前条目目录；选择共享资源时放到共享目录。
- 文件名会自动整理，重名时追加序号。
- 可按内容区、系列、版本或条目、目录、引用状态、类型、日期与关键词筛选，筛选条件写在网址里。
- 支持网格与列表两种视图，可以批量重命名、移动、删除，改名或移动会同步改写正文里的引用。
- 引用状态分三种：已引用、未引用、孤儿。孤儿指条目已经删除、文件还留在磁盘上。
- 详情里可以复制路径或 Markdown 引用，也可以把整个条目导出成 ZIP。
- 「导入条目」接受条目 ZIP，只新建条目，不覆盖已有内容。
- 配置了云端图片存储后，上传的图片进入云端，列表会一起显示；没有配置时只使用本地文件。

## 快照

快照页只导出和导入设置，导出的文件包含设置与说明信息，不包含内容、图片和账号密钥，不能当作整站备份。

导入前会先比对并展示会变化的设置，确认后才写入。设置文件损坏时，快照页同样进入只读状态。

## 注意事项

- 后台只在开发环境可写，生产构建只读。线上想改内容或设置，要改仓库文件后重新构建。
- 内容与设置写的是仓库文件，图片按存储配置写入；改完记得提交；不要一边用后台编辑，一边手动改同一个设置文件。
- 后台的界面偏好（顶部导航、侧栏模式、编辑器布局）只保存在当前浏览器里，不写进仓库。
