后台入口是 `/admin/`。它把主题设置、内容、资源与快照放在同一套壳层里，但只在开发环境具备写入能力；生产构建输出的是只读静态页面，写入接口不会暴露。本文按导航顺序说明各模块的职责与边界。

![后台主题设置页，左侧导航与分组表单](/images/demo/admin-console.png)

## 概览

`/admin/` 是后台首页，汇总内容规模、标签分布、字数与最近条目。它读取各集合的已发布条目与草稿数量，开发环境下显示包含草稿的维护者视图。生产环境是否输出公开版本由 `site.json` 的 `adminOverview.publicVisible` 决定，关闭时显示配置的提示文案。

概览不提供编辑操作，用途是快速判断内容分布与最近改动，再进入对应模块。

## 主题

`/admin/theme/` 编辑全部主题设置。服务端按 `src/data/settings/` 的五个 JSON 文件存储，界面拆成七个分组：

| 分组 | 主要设置 |
| --- | --- |
| 站点设置 | 站点标题、默认 SEO 描述、语言、页脚、窄屏标题宽度、页面外缘间隙、概览文案、站点图标、备案信息、社交链接 |
| 侧栏设置 | 侧栏站点名、窄屏标题、引用文案、导航项标签与顺序、分隔线、侧栏图标 |
| 首页设置 | Hero 图与替代文本、导语、更多入口 |
| 内页设置 | 各列表页标题与副标题、RSS 开关、动态默认作者、文章元信息、浏览数据、浮动操作列 |
| 代码显示 | 代码块行号 |
| 条目版本 | 版本名称是否显示，以及显示在标题后还是版本号后 |
| 排版字体 | 正文、正文副本、等宽与品牌四个字体角色 |

保存时控制台把当前草稿与 `revision` 一起提交到 `/api/admin/settings`。服务端在写锁内校验版本与字段，通过后以文件事务写入设置文件并清理缓存。检测到外部更新时返回 409，控制台保留草稿并要求重新同步，避免覆盖另一处修改。

设置文件出现非法 JSON、根节点不是对象、读取失败或存在会被静默修补的字段时，控制台进入只读状态并列出问题，不接受保存。渲染与构建仍会按内置默认值兜底，因此只读状态不会让站点停止工作。

## 内容

`/admin/content/` 是内容管理控制台，覆盖 `blog`、`projects`、`bits`、`devlog`、`about` 五个集合。新建条目时按标题生成 `YYYY-MM-DD-title` 形式的条目 ID，写入对应集合目录；`about` 是固定单页，只编辑正文，不支持新建与删除。

| 集合 | 新建 | 删除 | 草稿 | 正文图片上传 | 图片选择器 |
| --- | --- | --- | --- | --- | --- |
| `blog` | 是 | 是 | 是 | 是 | 否 |
| `projects` | 是 | 是 | 是 | 是 | 是 |
| `bits` | 是 | 是 | 是 | 否 | 是 |
| `devlog` | 是 | 是 | 是 | 是 | 是 |
| `about` | 否 | 否 | 否 | 否 | 否 |

列表支持按集合、草稿状态、系列与版本过滤，也支持排序、正文搜索、分页、批量改状态与批量导出。编辑页按 `[collection]/[edit]/[...entryId]` 组织，开发环境挂载 Markdown 编辑器，可插入图片、图库与公式。内容写入落到 `content/`，与手工编辑 Markdown 使用同一份源文件。

## 资源

`/admin/resources/` 把图片与附件放在同一个工作区。旧地址 `/admin/images/` 会 301 到新地址。左侧内容库按集合、系列、版本或条目、目录展开，右侧预览与详情抽屉处理具体文件。

| 操作 | 落点或行为 |
| --- | --- |
| 上传图片 | 当前条目的 `images/` |
| 上传附件 | 当前条目的 `files/` |
| 上传到共享资源 | `content/<collection>/_shared/images` 或 `_shared/files` |
| 筛选 | 集合、系列、版本或条目、目录、引用状态、类型、日期与关键词，状态写入 URL |
| 批量操作 | 重命名、移动、删除前确认，选择状态跟随当前筛选 |
| 详情 | 复制路径与 Markdown 引用、重命名、移动、删除、导出条目 ZIP |
| 引用状态 | 统计正文与 frontmatter 的引用次数，区分已引用、未引用与孤儿 |

共享资源与未归属资源同级显示，不要求条目已经有 Markdown 主文件。资源页支持导入整条目 ZIP，导出走内容接口；文本附件可以直接预览。云端来源需要对象存储凭据，未配置时使用本地目录。

## 数据

`/admin/data/` 导出与导入设置快照，用于迁移或备份。快照包含 `settings` 作用域，不包含内容、图片与凭据；包结构含 `schemaVersion`、生成时间与排除项清单。导入使用与主题设置相同的保存接口，提交前先做预检；失败时不会写入半份配置。

## 开发环境与生产环境

写入能力由构建输出模式区分。`npm run dev` 输出 `server` 模式，后台页面与 `/api/admin/*` 可读写；`npm run build` 输出 `static` 模式，后台是只读静态壳，API 一律返回 404。`npm run check:prod-artifacts` 会在产物上断言后台页面不含写入相关的界面标记，也不输出导航入口。

开发环境使用的界面偏好，例如顶部导航可见性、侧栏导航模式与编辑器默认布局，保存在浏览器 localStorage，不写入仓库。它们不会随站点部署，也不会影响其他访问者。

内容字段与目录规则见[内容模型与目录式条目](/blog/2026-10-03-content-model/)；主题设置里的版本名称选项如何作用于列表与文章页，见[发布与版本管理](/blog/2026-10-09-release-and-versioning/)。
