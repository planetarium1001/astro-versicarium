后台是主题自带的内容管理界面，用来写内容、管理图片和修改站点设置。它直接读写仓库里的文件，不需要数据库。

后台只在本地开发时能保存。用 `npm run dev` 启动后，打开 `http://localhost:4321/admin/` 进入；构建出来的线上站点只有只读页面。

```bash
npm run dev
```

## 五个页面

| 页面 | 能做什么 |
| --- | --- |
| 概览 | 看内容数量、热门标签、总字数、最近条目与写作活动 |
| 主题 | 修改站点、侧栏、首页、内页等七组设置 |
| 写作 | 列出、筛选、新建与编辑五个区的内容 |
| 资源 | 管理图片与附件，查看引用状态 |
| 快照 | 导出、校验与导入设置快照 |

## 概览

概览显示内容数量、热门标签、总字数、最近条目和写作活动。本地开发时草稿也会列出来并标注。

## 主题设置

主题页把设置分成七组，保存后写入 `src/` 下的五个设置文件，也可以手动改这些文件：

| 分组 | 管什么 |
| --- | --- |
| 站点设置 | 站点名称、描述、语言、时区、页脚、社交链接、站点图标与布局尺寸 |
| 侧栏设置 | 侧栏的站点名、引语、导航项与顺序、订阅按钮、主题按钮和后台入口 |
| 首页设置 | 首页头图、导语、补充文案，以及「更多」入口的文字与链接 |
| 内页设置 | 各列表页的标题、归档显示方式、动态默认作者、日期显示、分页等 |
| 条目版本 | 版本名称显示在哪里：隐藏、放在版本号前或版本号后 |
| 代码显示 | 代码块是否显示行号 |
| 排版字体 | 正文、引用、等宽与品牌四个字体用途，以及字库覆盖范围 |

改完点「检查配置」，后台只校验并列出会变化的项，不写文件；确认后点「保存」，只写入有变化的分组。想放弃本轮修改，点「重置更改」。

如果设置文件在别处被改过，或另一个窗口先保存了，页面会提示文件已在外部更新，并保留当前填写的内容。点「重置更改」回到最新内容再改，点「重新检测」重新读取文件和状态。设置文件出现格式错误时，后台进入只读状态，列出出问题的文件、位置和原始错误；先修好文件，再点「重新检测」。

站点图标可以在站点设置里上传 PNG：不超过 256KB，边长 16–512 像素，接近正方形。想用 SVG，把文件放进 `public/`，再在站点设置里填写路径。

## 浏览数据

「主题 → 内页设置」里的「浏览数据」控制 PV（浏览量）与 UV（访客数）的显示。后台只控制是否显示、显示位置与文字前缀，不保存统计数据；设置写在 `src/data/settings/ui.json` 的 `viewStats` 里：

| 设置项 | 作用 |
| --- | --- |
| `showPv`、`showUv` | 是否显示浏览量、访客数，默认关闭 |
| `pvLabel`、`uvLabel` | 数字前的文字，默认「浏览」「访客」，最多 8 个字符 |
| `onArticleMeta` | 显示在文章页的元信息行 |
| `onIndexPages` | 显示在博客、动态、更新、归档等列表页底部 |

主题只渲染槽位与样式，不内置统计服务。开启显示后，数字要由站点自己提供：在 `src/scripts/view-stats.ts` 里从统计服务取数，再填入页面上的浏览数据槽位。没有填值的槽位保持隐藏，不占位、不引起页面跳动。

槽位按页面区分 PV 与 UV，并带有当前页面的路径与名称，便于按页面取数。`src/lib/view-stats.ts` 提供写入函数与就绪事件，接入方式见[站点结构](https://github.com/planetarium1001/astro-versicarium/blob/main/docs/architecture.md)的「浏览数据」一节。

## 写作

写作页按文章、项目、动态、开发日志和关于页五个区列出内容，可以按区、草稿状态、年份、标签、排序与关键词筛选。

新建条目默认是草稿；编辑完保存，取消草稿即为发布。编辑器提供 Markdown、预览和大纲，以及图片、画廊、公式、折叠内容和摘要分隔的插入。博客条目可以「新建版本」，以系列最新版为模板生成一份新草稿，其余区没有这个动作。

删除的条目会移到回收站目录，不会马上从磁盘消失，需要时可以手动移回。支持批量改发布状态、删除与导出源文件，一次最多 200 条。关于页是固定单页，只能编辑正文。保存博客正文时，如果正文引用的本地图片不存在，后台会拒绝保存。

## 资源

资源页把图片和附件放在同一个工作区，左侧目录按内容区、系列、版本或条目展开，共享资源是每个内容区共用的一份。

上传的图片和附件放到当前条目目录；选择共享资源时放到共享目录。文件名会自动整理，重名时追加序号。列表可以按内容区、系列、版本或条目、目录、引用状态、类型、日期与关键词筛选。

支持网格与列表两种视图，可以批量重命名、移动、删除；改名或移动会同步改写正文里的引用。引用状态分三种：已引用、未引用、孤儿，孤儿指条目已经删除、文件还留在磁盘上。详情里可以复制路径或 Markdown 引用，也可以把整个条目导出成 ZIP。「导入条目」接受条目 ZIP，只新建条目，不覆盖已有内容。配置了云端图片存储后，上传的图片进入云端，列表会一起显示。

## 快照

快照页只导出和导入设置。导出的文件包含设置与说明信息，不包含内容、图片和账号密钥，不能当作整站备份。导入前会先比对并展示会变化的设置，确认后才写入。设置文件损坏时，快照页同样进入只读状态。

## 注意事项

后台只在开发环境可写，生产构建只读。线上想改内容或设置，要改仓库文件后重新构建。内容与设置写的是仓库文件，图片按存储配置写入，改完记得提交；不要一边用后台编辑，一边手动改同一个设置文件。后台的界面偏好只保存在当前浏览器里，不写进仓库。

完整的写入流程见[后台使用](https://github.com/planetarium1001/astro-versicarium/blob/main/docs/admin-console.md)。
