2026-10-02 的仓库还叫 `astro-whono-tweaked`，是 `cxro/astro-whono` 的下游分支。上游的双栏布局、内容集合、本地后台、Markdown 扩展与字体子集全部保留，改动集中在长文阅读与布局尺寸上，没有动内容模型。

## 阅读改造

这一版新增了文章目录、右下角浮动操作列、主题切换涟漪，并重做了阅读模式的入口与过渡。

文章目录在宽屏（视口 ≥ 1280px）上作为壳层右侧的第四列常驻，正文宽度不变；进入阅读模式后门槛降到 1024px，侧栏收拢腾出的空间正好放得下目录。窄屏时目录折叠在正文顶部，可以展开。收起状态记在 localStorage，并在首次绘制前生效；滚动时高亮当前小节，点击跳转后目标段落短暂铺一层底色，同时把焦点落到标题上。

浮动操作列常驻页面右下角，按需出现：阅读模式只出现在文章详情与沉浸页，回到上次阅读位置只在存在可回退位置时出现，回到顶部在页面不可滚动时置灰。阅读模式的入口从左栏移到浮动列，桌面端收拢侧栏、放宽正文，窄屏按脚本量出的真实高度收起顶部横条，进出都遵循系统的减少动效设置。

主题切换涟漪以点击处为圆心做圆形展开，使用 View Transitions API；浏览器不支持该接口或系统要求减少动效时直接切换，不做动画。

阅读位置记忆分两种。跨次打开按路径存 localStorage，同时记录标题、段内偏移与滚动比例，布局变化时优先用标题定位；本次会话内用位置栈，点击目录跳转或回到顶部之前都会入栈，可以原路返回。

首屏入场时先按收起态渲染，正文出来后再平滑展开目录列，避免从列表页进来时右侧突然多出一块。目录把手贴在「本文目录」一行右端，收起后只留 34px 窄轨，三种状态下位置都不动。

## 布局与细节

侧栏从 320px 收到 224px，前台与后台共用同一组内边距 token，两侧内容宽度一致。壳层宽度改为随视口自适应，大屏不再固定 1100px。同时修了前后台侧栏内容宽度不一致、后台偏好设置弹层超出视口两个问题。

Markdown 扩展沿用上游：提示块、图注、画廊、公式、代码块与折叠都可以直接写。首页首屏的 critical CSS 是一份手写快照，这一版补了检查脚本，防止它与真实样式漂移。

## 内容组织

内容仍是上游的四个集合：`essay`、`bits`、`memo`、`about`，对应随笔、絮语、小记与关于。内容放在 `src/content/`，一个 Markdown 文件就是一条内容；图片放在 `public/`，正文用绝对路径引用。没有项目集合，也没有开发日志集合，项目介绍与开发进展只能当作长文写进随笔。

归档是上游的目录视图，按时间从新到旧排列。后台沿用上游的 Admin Console，在开发环境下可以修改主题设置、写内容、管理图片与查看数据；生产构建只保留只读页面。浏览数据与备案字段的展示槽位也一并保留。

站点还保留上游的 RSS（归档与分栏两路）、浅色与深色模式、絮语草稿生成器与自托管子集字体。上游的完整说明在 `README.upstream.md`，本分支的增量写在仓库 README 里。上游与本仓库都使用 MIT 许可。

## 主题更新与部署

这一版没有主题更新命令。上游或本仓库有新提交时，只能手工对照 diff 合并，站点无法单独获取主题改动，主题与站点尚未分开。

部署使用 GitHub Pages 项目页，仓库名是 `astro-whono-tweaked`。工作流从仓库名推导站点地址与部署子路径，改仓库名后地址随之变化。

这一版的价值在阅读体验：目录、浮动操作列、阅读模式与位置记忆构成了后来一直保留的骨架。内容模型还是上游的单文件四集合，系列、项目版本、开发日志与分页都不存在。约两周后的内容模型重做换掉了这套集合，内容根也在 10-19 迁出 `src/`。
