2026-10-02 的仓库叫 `astro-whono-tweaked`，派生自 `cxro/astro-whono`。Whono 的双栏布局、内容集合、本地后台、Markdown 扩展与字体子集全部保留，改动集中在长文阅读与布局尺寸上。

## 阅读改造

- 新增文章目录、右下角浮动操作列与主题切换涟漪。
- 重做阅读模式的入口与过渡。

文章目录在宽屏（视口 ≥ 1280px）上作为壳层右侧的第四列常驻，正文宽度不变；进入阅读模式后门槛降到 1024px，侧栏收拢腾出的空间正好放得下目录。窄屏时目录折叠在正文顶部，可以展开。

- 目录的收起状态记在 localStorage，首次绘制前生效。
- 滚动时高亮当前小节，点击跳转后目标段落短暂铺一层底色，焦点落到标题上。
- 浮动操作列常驻右下角，按需出现：阅读模式只出现在文章详情与沉浸页，回到上次阅读位置只在存在可回退位置时出现，回到顶部在页面不可滚动时置灰。
- 主题切换涟漪以点击处为圆心做圆形展开，使用 View Transitions API；浏览器不支持该接口或系统要求减少动效时直接切换。

阅读位置记忆分两种。跨次打开按路径存 localStorage，同时记录标题、段内偏移与滚动比例，布局变化时优先用标题定位；本次会话内用位置栈，点击目录跳转或回到顶部之前都会入栈，可以原路返回。

## 布局与细节

- 侧栏从 320px 收到 224px，前台与后台共用同一组内边距，两侧内容宽度一致。
- 壳层宽度改为随视口自适应，大屏不再固定 1100px。
- 修掉前后台侧栏内容宽度不一致、后台偏好设置弹层超出视口两个问题。

Markdown 扩展沿用 Whono：提示块、图注、画廊、公式、代码块与折叠都可以直接写。首页首屏的 critical CSS 是一份手写快照，这一版补了检查脚本，防止它与真实样式漂移。

## 内容组织

内容仍是 Whono 的四个集合：`essay`、`bits`、`memo`、`about`，对应随笔、絮语、小记与关于。

| 集合 | 位置 | 内容 |
|---|---|---|
| `essay` | `src/content/essay/` | 长文随笔，一个 `.md` 一条 |
| `bits` | `src/content/bits/` | 短动态，一个 `.md` 一条 |
| `memo` | `src/content/memo/index.md` | 固定单页 |
| `about` | `src/content/about/index.md` | 关于页 |

- 内容放在 `src/content/`，一个 Markdown 文件就是一条内容。
- 图片放在 `public/`，正文用绝对路径引用。
- 没有项目集合，也没有开发日志集合，项目介绍与开发进展只能当成长文写进随笔。

归档是 Whono 的目录视图，按时间从新到旧排列。后台沿用 Whono 的 Admin Console，在开发环境下可以改主题设置、写内容、管理图片与查看数据，生产构建只保留只读页面。

站点保留 Whono 的 RSS（归档与分栏两路）、浅色与深色模式、絮语草稿生成器与自托管子集字体。Whono 与本仓库都使用 MIT 许可。

## 主题更新与部署

这一版没有主题更新命令。主题改动只能手工对照差异合并，站点无法单独获取主题更新，主题与站点还没有分开。

部署使用 GitHub Pages 项目页，仓库名是 `astro-whono-tweaked`。工作流从仓库名推导站点地址与部署子路径，改仓库名后地址随之变化。

这一版的价值在阅读体验：目录、浮动操作列、阅读模式与位置记忆构成了后来一直保留的骨架。内容模型还是单文件的四集合，系列、项目版本、开发日志与分页都不存在。两周后的内容模型重做换掉了这套集合，内容根也在 10-19 迁出 `src/`。
