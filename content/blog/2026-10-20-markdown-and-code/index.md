Versicarium · 垄录 的正文渲染建立在 Markdown 管线之上。标题、列表、表格与引用按 Markdown 规范渲染，提示块、代码工具栏与数学公式由 `src/plugins/` 中的插件扩展，末尾链接组由正文渲染层处理。以下语法均由 1.0.0 预览版的当前管线支持。

## 基础排版

段落之间留空行。标题从二级开始，文章标题由 frontmatter 的 `title` 渲染，正文里不再重复一级标题。

- 无序列表使用 `-` 或 `*`。
- 有序列表使用数字加句点。
- 行内代码使用反引号，例如 `npm run dev`。

> 引用块用于摘录或旁注。引用内的 Markdown 正常渲染。

| 写法 | 结果 |
| --- | --- |
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `[文字](https://astro.build/)` | [文字](https://astro.build/) |

链接直接写完整地址。站内链接使用以 `/` 开头的路由，例如 `/blog/2026-10-20-content-model/`，不要写相对文件路径，否则构建后可能指向错误位置。

## 提示块

提示块使用容器指令，类型支持 `note`、`tip`、`info`、`warning`，方括号内的标签可以省略。

:::tip[提示]
提示块适合放补充说明、操作建议或阅读前提。正文继续按 Markdown 渲染。
:::

写法如下：

```markdown
:::tip[提示]
提示块适合放补充说明、操作建议或阅读前提。正文继续按 Markdown 渲染。
:::
```

指令必须成对闭合。开头写 `:::类型[标签]`，结尾单独一行 `:::`。未知类型会回退为 `note`，仍获得提示块样式。

## 代码高亮

围栏代码块标注语言后交给代码高亮管线，渲染时套上工具栏，显示语言、行数与复制按钮。行号由后台的代码块行号设置控制。

```ts
export type Entry = {
  title: string;
  date: string;
};

export const isPublished = (entry: Entry): boolean => entry.date.length > 0;
```

未标注语言的围栏按纯文本处理，工具栏显示 `text`，不做语法高亮。需要展示 Markdown 指令本身时，用四个反引号包住三个反引号的示例，外层围栏的语言写 `markdown`。

## 数学公式

行内公式使用双美元符号，块级公式把 `$$` 单独成行。

行内公式示例：$$a^2 + b^2 = c^2$$。

$$
\int_0^1 x^2 \, dx = \frac{1}{3}
$$

单个 `$` 不是公式定界符，会按普通文本输出。代码块与行内代码中的 `$$` 原样保留，不进入公式渲染。公式样式只在页面确实包含公式时加载，普通文章不会额外请求数学字体。

## 末尾链接组

`projects` 与 `devlog` 的正文末尾可以写一组外链，渲染为右对齐的链接行。链接组前留一个空行，与正文分段；链接组由连续若干行组成，每行只包含 Markdown 链接与分隔符。

```markdown
项目正文的最后一段。

[仓库](https://github.com/planetarium1001/astro-versicarium) · [示例站](https://planetarium1001.github.io/astro-versicarium/)
```

渲染时链接按书写顺序排列，之间只保留间隔，不输出分隔符。链接组不参与摘要派生，也不会在正文中重复出现。

这套写法只对 `projects` 与 `devlog` 生效。博客正文不使用链接组；文中的普通链接仍按行内链接渲染，末尾连续写多行链接也不会变成右对齐链接行。
