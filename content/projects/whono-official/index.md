Whono 官方主题（`cxro/astro-whono`）是 Versicarium 的上游项目，也是本仓库的起点。上游首次提交为 `66ded04`（2026-01-17），提供双栏布局、内容集合、本地后台控制台与 Markdown 渲染管线。

本仓库保留上游的提交历史与核心结构：侧栏导航与内容区的双栏壳层、后台的模块划分、Markdown 扩展、字体子集流程与絮语草稿生成器都来自上游。在此基础上，Versicarium 增加项目多版本文档、资源工作区、分页设置与主题更新通道，并把内容集合重组为 blog / projects / bits / devlog / about。

上游采用 MIT 许可，版权声明在仓库 LICENSE 中以 cxro 与 Planetarium（modifications）并列保留。修改与再分发遵循同一许可。

这个条目只作为上游参考记录，不参与 Versicarium 的版本序列。上游的演示与仓库地址在下方链接中给出；本站自身的版本历史记在 Versicarium 项目中。
