这一版没有做较大的改动。双栏框架、后台控制台、Markdown 渲染与字体子集都沿用 `cxro/astro-whono`，改动集中在长文阅读：文章目录进宽屏布局第四列，窄屏折到正文顶部，可以收起并记忆状态，滚动时高亮当前小节，跳转后短暂高亮目标章节；右下角加浮动操作列，放阅读模式、回到上次位置与回到顶部；主题切换改成以点击处为圆心的涟漪过渡；侧栏从 320px 收到 224px。阅读模式会收起侧栏，正文占满内容区；阅读位置按路径记忆，回到文章时可以接着读。浮动列常驻右下角，按需显示三个按钮，窄屏顶栏也会随阅读模式收起。

## 内容与边界

内容仍是上游的四个集合 `essay`、`bits`、`memo`、`about`，一条内容一个 Markdown 文件，放在 `src/content/`。图片单独放进 `public/`，正文写绝对路径，图片与条目之间没有绑定。项目与开发日志没有独立集合，只能写成随笔里的一篇。部署仍是 GitHub Pages 项目页，工作流按仓库名推导站点地址与 base。

主题还没有更新命令，上游改动只能手工对照 diff 合并。后台仍是上游的 Admin Console，能改站点名称、侧栏与首页文案，也能写随笔、絮语、小记与关于页，图片上传默认保存在本地。没有项目与开发日志集合，没有版本路由，也没有全站归档。

0.5.0 的版本号一直用到 10-15，内容模型与主题更新在此期间各改一次。
